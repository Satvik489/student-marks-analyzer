# Student Marks Analyzer

A beginner-friendly Python project that calculates a student's academic performance based on marks in Physics, Chemistry, and Mathematics.

## Features
- Accepts student name and subject marks.
- Validates marks between 0 and 100.
- Calculates total marks and percentage.
- Assigns a grade based on percentage.
- Identifies the highest-scoring subject.
- Generates a student performance report.

## Technologies Used
- Python
- Google Colab

## How It Works
The program takes marks as input, validates them, and calculates the student's total, percentage, grade, and highest-scoring subject.
